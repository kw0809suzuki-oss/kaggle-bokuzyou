# Kaggriculture Dynamic Model

動的モデル専用フォルダ。現在のモデルは [MODEL.md](MODEL.md)。

- 親目的はOfficial Kaggriculture Worldでterminal self Cash（最終所持金）を上げること。
- Battle・Replay・実験コードの正本は [kw0809suzuki-oss/kaggle-bokuzyou](https://github.com/kw0809suzuki-oss/kaggle-bokuzyou)。このフォルダへ複製しない。
- 参照元のmainを最新研究座標とみなさない。Evidenceはbranch・commit・Run・Battleの対象範囲で識別する。
- Battleは正本Evidence、Viewはその切り出し、JudgeはViewへの判定。Viewの不具合や判定失敗でBattleを上書きしない。
- Agent・Candidate・攻略実装・実験コードは置かない。次の実装も決めない。
- モデルは暫定的な表現。仮説、実装、依頼文の索引を証明扱いせず、Evidenceを越えて確定しない。
